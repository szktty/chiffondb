# examples

A collection of examples showing how to use ChiffonDB.

## List of examples

| Directory | Description |
|-----------|-------------|
| [basic](./basic/) | Basic workflow: init / schema apply / info |
| [social-graph](./social-graph/) | Building and querying a social graph with User / Project / Document |

## How to run

Run the `run.sh` script in each example directory.

```bash
bash examples/basic/run.sh
bash examples/social-graph/run.sh
```

The binary built at the repository root is used automatically.
